# ⚙️ GTAConfig - Installation Guide / Guía de Instalación

---

## 🇺🇸 English

Thank you for downloading my config! ❤️

### 📥 How to install?

1. Download the `GTAConfig` file.
2. Once downloaded, extract the `.zip` file.
3. Open the extracted folder and select **everything inside**.
4. Copy all the files and folders.
5. Go to your `Victory` folder and paste everything inside.
6. That's it! Your config is now installed. ✅

### 📥 ¿Cómo instalarla?
